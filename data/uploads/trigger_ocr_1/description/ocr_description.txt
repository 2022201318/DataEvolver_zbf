Task goal:
Prepare training-ready structured data from screenshot/scanned document images.

Mandatory capability:
- read text from image pixels (OCR), not from filename hints
- handle screenshot and scanned page layouts
- normalize extracted fields into strict JSON schema

Hard constraints:
- if OCR confidence is low, include a confidence flag and continue
- preserve original numeric units
- do not hallucinate fields that are not visible in the image

Important:
This task is multimodal image-to-structured-data transformation and requires explicit OCR operator support.
