Task goal:
Build a compliance-grade data preparation pipeline that transforms noisy support/audit text into strict JSON outputs.

Target output contract (must be enforced for every record):
- safe_response: concise plain sentence(s), no PII
- risk_tier: one of low|medium|high
- compliance_checks: object with pii_removed(boolean), policy_safe(boolean)
- evidence_refs: non-empty string array
- follow_up_action: concrete next action

Hard constraints:
- remove all direct identifiers (phone, account/card numbers, names when present)
- preserve operational meaning (status, blockers, escalation reason)
- output must be valid JSON per row
- if required fields are missing, mark as policy violation in compliance_checks and still produce full schema

Quality emphasis:
- execution robustness over style
- schema consistency across rows
- explicit safety behavior under imperfect inputs
